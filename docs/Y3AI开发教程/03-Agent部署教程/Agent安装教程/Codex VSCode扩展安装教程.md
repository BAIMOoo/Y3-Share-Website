## 安装与打开 {#installation}

[![VS Code 下载页：① Windows，② User Installer 的 x64 或 Arm64](../img/vscode-download.png)](../img/vscode-download.png "点击查看原图")

1. 安装或更新 [VS Code](https://code.visualstudio.com/download)，在 VS Code 按 `Ctrl+Shift+X`，搜索 `Codex`。
2. 核对发布者 **OpenAI**、标识 `openai.chatgpt`，点击“安装”。若提示版本不兼容，先更新 VS Code。
3. 从侧栏打开 Codex，或按 `Ctrl+Shift+P` 搜索 `Codex: Open Codex Sidebar`。

[![OpenAI 发布的 Codex 扩展](../../Y3_AI_images/image26.png)](../../Y3_AI_images/image26.png "点击查看原图")

[![Codex 面板入口](../../Y3_AI_images/image27.png)](../../Y3_AI_images/image27.png "点击查看原图")

能打开 Codex 侧栏即安装成功。
