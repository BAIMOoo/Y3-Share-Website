## 当前推荐 {#recommendations}

目前进行 Y3 AI 开发，推荐优先使用 **Codex 或 Claude Code**。

根据当前使用体验，Y3Maker 仍有较多 bug，性能与主流 Agent 相比也存在差距，暂不推荐作为首选。已有用户仍可查阅 [Y3Maker 配置说明](../AssistantDevelopment.md)。

<span id="作者个人推荐" className="legacy-anchor" />

## 作者个人推荐 {#personal-recommendation}

以下按作者个人的推荐优先级排序：

| 选择范围 | 推荐顺序 |
| --- | --- |
| Agent | **Codex** > Claude Code |
| Codex 客户端 | **Codex App** > Codex CLI > Codex VS Code 扩展 |
| Claude Code 客户端 | **Claude Code CLI** > Claude Code VS Code 扩展 |

<span id="接下来怎么做" className="legacy-anchor" />

## 接下来怎么做 {#next-steps}

1. 先完成 [Y3 项目环境](../EnvironmentSetup.md)的准备。
2. 按推荐优先级选择 [Codex App](<./Agent安装教程/Codex App安装教程.md>)、[Codex CLI](./Agent安装教程/Codex部署教程.md)、[Codex VS Code 扩展](<./Agent安装教程/Codex VSCode扩展安装教程.md>)、[Claude Code CLI](<./Agent安装教程/Claude Code CLI部署教程.md>)或 [Claude Code VS Code 扩展](<./Agent安装教程/Claude Code for VSCode 扩展安装以及配置教程.md>)，完成客户端安装。
3. **必做：[Codex/Claude 模型配置](<./CC Switch安装与使用.md>)**，优先通过可视化界面填写第三方服务商的 **Base URL、API Key 和模型 ID**，启用后验证回复；已有官方账号再选择官方登录路径。
4. 按[用外部 Agent 开发 Y3](../04-如何使用AI开发Y3项目.md)打开工程，并通过[连接 Y3 配套MCP](./MCP接入.md)接入所需工具。
