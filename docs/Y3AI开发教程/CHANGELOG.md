# Y3Maker 更新记录

以下为 2026 年 3～6 月的知识库、流程和模板更新，未逐条对应最低软件版本。

## 2026 年 6 月

- 整理并优化功能模板，包含结算、二次确认弹窗、AOE 点选、UI 对象池、难度选择、暂停弹窗等模板。
- 新增 HUD 相关模板，包含主控台、顶部信息、统计信息。
- 修复模板 Lua 语法问题和 LuaLS 注解诊断问题。

## 2026 年 5 月

- 更新 A/B/C/D 四个等级的功能模板体系，并新增和迭代多选一、技能创建、投射物技能、AOE 技能、暂停游戏、羁绊计数器、漂浮提示 UI、属性系统、结算、背包、商店、逻辑框架等模板。
  - A 级：通用模板，低依赖，传参即可复用。
  - B 级：常用业务模板，需要少量配置或回调。
  - C 级：复杂业务模板，需要补 Adapter 或接口后接入。
  - D 级：项目专用模板，业务绑定较深，移植成本高。
- 新增地编模板和模板导出能力，支持地形、装饰物、自定义资源、碰撞等内容的导出导入。
- 整理物编编辑参考文档，补充 `y3-obj-edit` 的使用资料。
- 补充实战参考知识库。
- 清理废弃模板和冗余文件，修复部分模板编码问题。

## 2026 年 4 月

- 新增快速环境配置能力，降低首次配置成本。
- 新增自动化测试能力，支持测试计划生成、UI 点击、Lua 执行、日志检查、截图存证和测试报告输出。
- 优化资源下载、保存地图等基础操作流程。
- 优化 UI 生成能力，支持网格、列表、控件模板识别、物品栏 UI、控件适配、场景 UI、时间轴动画等内容。
- 完善 Lua 开发流程，要求 Lua 编写走 `y3-lua-pipeline`，并新增 `y3-lua-review` 检查机制。
- 整合物编生成和物编编辑能力到 `y3-obj-edit`，优化物编属性修改方式。
- 新增和完善地形生成能力，补充地形生成经验归档。
- 优化策划共创流程，增加策划案结构检查、执行案规范和引擎能力边界检查。
- 大量整理知识库，补充属性、KV、存档、阵营、事件、伤害、运行模式、地形、物编、UI 等系统资料。
- 清理冗余规则和旧引用，将多处旧路径改为相对路径。

## 2026 年 3 月

- 新增 `.y3maker` 基础目录、基础规则、skill 调用规则。
- 新增和完善 UI 生成能力，包含 UI 生成流程、UI JSON、UI 组件说明、适配规则等内容。
- 新增和完善 Lua 开发资料，包含事件、技能、单位、物品、计时器、event 写法等参考内容。
- 新增和完善物编生成能力，补充单位、技能、特效、伤害、单位属性枚举等资料。
- 新增编辑器资源下载、review 等辅助流程。
- 新增知识库初版和 agent 记忆功能初版。
- 新增策划案和 UI 生成相关示例。
- 清理无用脚本和废弃 skill，精简 skills 文件体积。
- 修复多处规则、路径、编码和模板问题。
