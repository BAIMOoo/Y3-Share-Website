# 02-如何连接开源游戏服务端框架

示例项目以 [Nakama](https://github.com/heroiclabs/nakama) 为例。其他提供 WebSocket 协议或 Lua SDK 引擎适配接口的服务端框架，也可以参考相同思路。

- Nakama 项目：[heroiclabs/nakama](https://github.com/heroiclabs/nakama)
- Nakama Lua SDK：[heroiclabs/nakama-defold](https://github.com/heroiclabs/nakama-defold)

<span id="1-部署-nakama" className="legacy-anchor" />

## 1. 部署 Nakama {#deploy-nakama}

安装并启动 Docker 后，在示例项目的 `maps/EntryMap/script/backend/nakama` 目录执行：

```bash
docker compose up --build -d
```

示例端口、默认用户和密码仅适合本地开发。公网环境必须修改密码、限制数据库和管理端口访问，并根据 Nakama 官方文档配置 TLS 与反向代理。

<span id="2-配置-y3-客户端" className="legacy-anchor" />

## 2. 配置 Y3 客户端 {#configure-client}

`main.lua` 中的 Nakama 配置示例：

```lua
local nakama = require 'nakama-lua-sdk.nakama.nakama'
local nakama_engine = require 'nakama-lua-sdk.nakama.engine.y3'

local client = nakama.create_client({
    host = '127.0.0.1',
    port = 7350,
    use_ssl = false,
    username = 'defaultkey',
    password = '',
    engine = nakama_engine,
    timeout = 10,
})
```

生产环境不要在客户端中保存高权限服务端密钥。这里的配置只用于演示认证流程。

<span id="3-认证并连接实时-socket" className="legacy-anchor" />

## 3. 认证并连接实时 Socket {#authenticate-and-connect}

```lua
nakama.sync(function ()
    local session = client.authenticate_email(
        'player@example.com',
        'replace-with-a-password'
    )
    nakama.set_bearer_token(client, session.token)

    local socket = client.create_socket()

    socket.on_error(function (message)
        local err = message and message.error or {}
        print('Socket 错误', err.message or '')
    end)

    socket.on_disconnect(function ()
        print('Socket 已断开')
    end)

    local ok, err = socket.connect()
    if not ok then
        print('连接失败', err)
        return
    end

    print('Nakama Socket 已连接')
end)
```

`socket.connect()` 在 coroutine 中会挂起当前 coroutine，直到后台 WebSocket 握手成功或失败。它不会阻塞 Lua 游戏线程，其他事件和定时器会继续运行。

也可以使用 callback：

```lua
socket.connect(function (ok, err)
    if not ok then
        print('连接失败', err)
        return
    end
    print('Nakama Socket 已连接')
end)
```

连接 callback 只会执行一次。握手阶段的错误通过 `(false, err)` 返回；连接成功后的网络错误交给 `socket.on_error`，断开事件交给 `socket.on_disconnect`。

<span id="4-在已有项目中接入-nakama" className="legacy-anchor" />

## 4. 在已有项目中接入 Nakama {#integrate-nakama}

1. 按“示例项目下载”页面接入 `custom_python.py` 和 `websocket.lua`。
2. 在编辑器内保存项目，使 `GlobalAPI.ws_*` 写入运行时生成产物。
3. 复制 `nakama-lua-sdk` 目录。
4. 复制或合并 `nakama/engine/y3.lua`，并在 `create_client` 时指定 `engine = nakama_engine`。
5. 先完成 HTTP 认证并设置 bearer token，再创建实时 Socket。
6. 分别验证正常连接、鉴权失败、服务端未启动和防火墙超时。

<span id="5-y3-引擎适配层" className="legacy-anchor" />

## 5. Y3 引擎适配层 {#engine-adapter}

Nakama SDK 默认面向 Defold。示例项目通过 `nakama/engine/y3.lua` 实现以下引擎接口：

- `http(...)`：使用 Y3 HTTP API 完成认证和 REST 请求。
- `socket_create(...)`：保存配置和消息处理器。
- `socket_connect(...)`：创建异步 WebSocket，并在真实握手完成后回调。
- `socket_disconnect(...)`：关闭连接并清理状态。
- `socket_send(...)`：编码并发送 Nakama 实时消息。
- `uuid()`：生成或读取玩家 UUID。

适配其他服务端框架时也应保持同样的线程边界：阻塞网络 I/O 放在 Python 后台线程，Lua 主线程只处理状态、队列和业务回调。
