# 01-示例项目下载

## 下载项目

- [下载 master 分支压缩包](https://gitee.com/baim00/y3-web-socket-project/repository/archive/master.zip)
- [查看 Gitee 项目](https://gitee.com/baim00/y3-web-socket-project)

示例仓库包含完整的 Y3 项目、WebSocket 客户端、Nakama Lua SDK 的 Y3 适配层，以及可通过 Docker Compose 启动的 Nakama 服务端配置。

示例 `main.lua` 默认提供按空格连接公开 WebSocket 回显服务的逻辑。公共服务可能随时不可用，实际项目应替换为自己控制的 `ws://` 或 `wss://` 地址。

## 主要文件

| 文件 | 作用 |
| --- | --- |
| `maps/EntryMap/custom_eca/custom_python.py` | Python 后台线程、连接状态和收发队列 |
| `maps/EntryMap/script/websocket.lua` | Lua 单调度器和事件式客户端 API |
| `maps/EntryMap/script/main.lua` | WebSocket 与 Nakama 示例入口 |
| `maps/EntryMap/script/nakama-lua-sdk/nakama/engine/y3.lua` | Nakama 的 Y3 引擎适配层 |
| `maps/EntryMap/script/backend/nakama` | Nakama 服务端 Docker Compose 配置 |

## WebSocket Lua API

```lua
local websocket = require 'websocket'

local client = websocket.connect('ws://127.0.0.1:18765', {
    connect_timeout = 5,
    max_batch = 20,
})

client:on_connected(function ()
    print('WebSocket 已连接')
    client:send('hello')
end)

client:on_message(function (_, message)
    print('收到消息', message)
end)

client:on_error(function (_, err)
    print('WebSocket 错误', err)
end)

client:on_closed(function ()
    print('WebSocket 已关闭')
end)
```

`connect_timeout` 是连接和关闭超时秒数，默认值为 10。`max_batch` 是每个 Lua 调度周期最多派发的消息数量，默认值为 20。

旧版本的 `update_interval` 和 `recv_timeout` 参数仍可传入以兼容已有代码，但不再控制网络接收；网络 I/O 已全部移到 Python 后台线程。

## 接入已有项目

1. 将 `custom_python.py` 合并到目标关卡的 `custom_eca/custom_python.py`。如果目标项目已有自定义 Python API，请保留原有代码和注册项。
2. 在 Y3 编辑器内保存项目。这一步不可省略，否则运行时生成产物中不会包含新的 `GlobalAPI.ws_*`。
3. 将 `websocket.lua` 放到目标关卡的 `script` 目录。
4. 确认运行环境能够导入 Python 的 `websockets.sync` 模块。
5. 使用上面的事件式 API 接入业务逻辑，然后分别测试正常连接、端口拒绝和防火墙超时。

更新 `custom_python.py` 后也必须再次在编辑器内保存；只替换文件但不保存，不会更新地图内的运行时代码。
